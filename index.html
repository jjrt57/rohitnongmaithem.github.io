Projects

QE Structure Studio

A web app and command-line tool for Quantum ESPRESSO. It reads pw.x input and output files, shows the structure in 3D and exports it as CIF, POSCAR, XYZ or nine other formats.

  • Reads scf, relax, vc-relax and md runs in whatever units pw.x printed, and input files for every ibrav.
  • Reports the space group, Wyckoff positions, lattice parameters and density, and plots energy and forces through a relaxation.
  • Flags runs that didn’t finish, SCF cycles that didn’t converge and inputs with common mistakes.
  • Checked against the geometry pw.x 6.7 prints for 36 reference inputs.

Built with Python, Streamlit, pymatgen, ASE and spglib.

View the code on GitHub

GoParser

A web app that reads Gaussian .log and .out files and pulls out what you would otherwise hunt for by hand: the SCF energy, HOMO and LUMO energies and gap, the method and basis set, the optimised geometry, and NBO charges and E(2) donor–acceptor tables.

It shows the molecule in an interactive 3D viewer, highlights each atom’s share of the HOMO or LUMO, and exports a plain-text report.

Built with Python, Streamlit and py3Dmol.

Open the app View the code on GitHub

QE-2-CIF

The command-line script that QE Structure Studio grew from. It takes the final relaxed structure from a Quantum ESPRESSO output and writes a .cif file for VESTA or Mercury.

Built with Python and pymatgen.
