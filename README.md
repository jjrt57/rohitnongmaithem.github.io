# Rohit Nongmaithem

Personal website: **https://jjrt57.github.io**

Computational chemist (M.Sc. in Physical and Computational Chemistry, Manipur University). I run and interpret DFT and TD-DFT calculations, build Python tools for chemistry data, and proofread scientific writing.

## Projects

- [QE Structure Studio](https://github.com/jjrt57/qe-structure-studio): reads Quantum ESPRESSO input and output files, shows the structure in 3D and exports it to CIF, POSCAR, XYZ and other formats.
- [GoParser](https://github.com/jjrt57/logparser): a web app for Gaussian `.log` and `.out` files. [Open the app](https://goparse.streamlit.app/).
- [QE-2-CIF](https://github.com/jjrt57/QE_2_CIF): a command-line converter from Quantum ESPRESSO output to CIF.
- [The Quantum ESPRESSO Necronomicon](https://medium.com/@rohitnongmaithem): a three-part Medium series on debugging DFT calculations on HPC clusters.
